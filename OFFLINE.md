# Foundry Tracker Offline 1.0.2

Esta edicion abre exportaciones JSON de Foundry Tracker con el boton Abrir exportacion JSON. Conserva emblemas, tablas, filtros y exportacion. La fecha mostrada es la del archivo, no una lectura actual del juego.

No incluye adb.exe, DLL de ADB ni los modulos tracker, memory_reader o adb_runtime. No conecta con el emulador, no usa root, no lee memoria ni recoge bajas nuevas. No hace falta abrir el juego. No importa ajustes ni instrucciones ejecutables del archivo: valida contadores y usa el catalogo incluido.

Crear un archivo nuevo usando la edicion con lector sigue implicando los riesgos de esa edicion. Offline no elimina ni revierte el uso previo de otros programas. No hay garantia de ausencia de sanciones ni autorizacion de NetEase.

Terminos generales revisados: https://unisdk.update.netease.com/html/latest_v4.html (seccion 5.5.7). Su aplicabilidad exacta al acuerdo aceptado por cada jugador no se verifico. Para distribuir un lector en vivo como autorizado se necesita la confirmacion del editor.

La edicion anterior se conserva. Cambios locales sin publicar.
